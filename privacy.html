Privacy Policy

Personal Google API client — last updated 17 November 2026

Who this covers

This policy describes a personal, single-user application operated by the owner of this site. It is not a product, it is not offered to other people, and it has no other users. It exists so that its operator can access his own Google account data from software running on his own computer.

What data is accessed

The application requests these Google OAuth scopes:

  • gmail.readonly, gmail.send, gmail.modify — reading, sending and labelling the operator's own mail
  • calendar — reading and writing the operator's own calendar events

Only the account that grants consent is accessed. The application cannot and does not access anyone else's Google account.

Where data goes

Mail and calendar data is fetched on demand to the operator's personal computer and used there. OAuth refresh tokens are stored in a file on that computer's local filesystem.

There is no server. No backend receives this data, no database stores it, and no analytics or tracking is performed. Nothing is sold, rented, shared with third parties, or used for advertising, and no Google user data is used to train machine learning models.

Content the operator explicitly chooses to process may be sent to a third-party AI model provider for that single request. This happens only on the operator's own instruction, for his own data, and is not retained by this application.

Retention and deletion

Nothing is retained beyond the local token file and whatever the operator saves himself. Access can be withdrawn at any time, which immediately and permanently ends the application's ability to read anything:

  • revoke it at Google Account → Data & privacy → Third-party apps, or
  • delete the local token file.

Limited Use

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

Questions about this policy can be directed to the site owner via github.com/soarewee.
